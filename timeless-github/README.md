# TIMELESS

25 минут до аварии на гидроузле. Голос отца звучит спустя десять лет.

Настольная игра для Windows. Анна ищет отца через портал между 1978, 2026 и 2074 годами. Нужно успеть закрыть предохранитель до затопления.

## Авторы

- Пешетбай Аяжан — фронтенд
- Убиев Жайдар — бэкенд

## Что внутри

- `app` — окно Electron (`main.cjs`)
- `game/backend` — сюжет, таймер и проверки на Python
- `game/desktop` — запуск локального сервера
- `game/static` — сцена на Three.js, интерфейс, голос и жесты

Готовые `TIMELESS.exe`, библиотеки и встроенный Python в репозиторий не входят: это собранная программа, а не исходный код.

Голосовая модель `vosk-ru.tar.gz` тоже не загружена через сайт: файл больше лимита GitHub в браузере (25 МБ). В игре она лежит в `static/vendor` и распознаёт команды локально, без облака.

## Управление

- Клавиатура: движение, прыжок, взаимодействие
- Голос: Vosk, офлайн, русская модель
- Жесты: MediaPipe Gesture Recognizer. Кулак — влево, два пальца — вправо, большой палец вверх — вперёд, большой палец вниз — назад, открытая ладонь — стоп, указательный палец — действие, мизинец и указательный — прыжок

## Технологии

Electron, Python, Three.js, SQLite, Vosk, MediaPipe.
